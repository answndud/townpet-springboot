## Browser vitals and route settle

## Reproduction

```bash
cd /Users/alex/project/townpet-springboot/frontend
corepack pnpm install --frozen-lockfile
corepack pnpm build
node scripts/measure-performance.mjs
corepack pnpm exec vite preview --host 127.0.0.1
corepack pnpm measure:browser
corepack pnpm exec playwright test e2e/desktop-visual.spec.ts --project=chromium
```

HTTP budget은 route median 100ms, API median 250ms이며 측정 스크립트가 5xx 또는 budget 초과 시 exit code 1을 반환한다. 이 기준은 local regression 감지용이지 production SLA가 아니다.

## 한계와 다음 측정

- local dev/preview 서버와 demo fixture이므로 CDN, TLS, 실제 사용자 네트워크, production compression을 반영하지 않는다.
- HTTP/API p50·p75는 서버 처리와 proxy 비용을 포함한다. 백엔드 원인 분석은 `docs/performance`의 백엔드 기록에서 별도로 수행한다.
- Browser vitals는 한 번의 preview 측정이며 장시간 interaction, 이미지가 많은 화면, 실제 모바일 환경을 포함하지 않는다.
- 다음 baseline은 같은 명령과 viewport로 측정하고, 환경이 바뀌면 별도 파일에 환경과 함께 기록한다.
