## SMTP 결과

Resend SMTP 587 연결을 VPS에서 시도했지만 TCP 연결이 timeout됐다. 따라서 실제 수신함 도착과 ERP Outbox `DELIVERED` 전이는 아직 증명하지 않았다. 애플리케이션에 설정된 SMTP 값을 변경하거나 성공으로 기록하지 않는다.

다음 운영 작업에서 netcup outbound SMTP 정책과 Resend 허용 포트(465/587/2525)를 확인한 뒤, 실제 수신 주소로 TownPet 인증·복구 메일과 KinderP 알림 메일을 각각 발송한다.

## 남은 검증

1. age 암호화 recipient key를 별도 failure domain에 보관하고 백업 파일을 외부 저장소에 업로드한다. 현재 서버에는 recipient key가 없어 암호화 단계는 실행하지 않았다.
2. SMTP 포트 차단 원인을 해결한 뒤 실제 메일 수신·Outbox 상태를 확인한다.
3. 롤백 시 외부 HTTPS smoke까지 자동화한다. 이번 rehearsal에서는 이전 이미지 health와 현재 이미지 복귀를 확인했다.

비밀번호, API key, SMTP credential, 백업 복호화 키는 이 문서에 기록하지 않는다.
