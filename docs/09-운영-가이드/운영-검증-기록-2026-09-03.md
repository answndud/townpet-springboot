## 관측성 감사와의 연결

실패 시각의 조사자는 사용자 응답의 `X-Trace-Id`를 시작점으로 backend의
`event=http_request`, `build_version`, status, duration을 조회할 수 있다. 이후
security rejection, state conflict, 비동기 consumer/delivery 결과, DB·MinIO health와
container restart/OOM 상태를 같은 시각에 대조한다. raw query, credential, token,
session secret, recipient email은 이 경로에 포함하지 않는다.
